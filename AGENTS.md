# Aganox Standards — agent guide

**Purpose**: Governance, app catalog, repo templates, and migration docs for all Aganox applications.

## Layout

| Path | Contents |
|------|----------|
| `docs/APP_CATALOG.md` | Active and archived repos |
| `docs/REPOSITORY_STANDARDS.md` | Required files, branching, CI |
| `docs/AI_DRIVEN_DEVELOPMENT.md` | Cursor rules and secret templates |
| `templates/.cursor/` | Copy to new app repos |
| `templates/.github/` | GitHub templates |
| `templates/gitignored/` | Examples for gitignored secret files |

## Commands

No build. Edit Markdown and templates; validate links manually.

## Agent constraints

- Update catalog when apps are added, archived, or renamed.
- Do not add application source code here.
- Mirror template changes into app repos when rolling out org-wide policy.
